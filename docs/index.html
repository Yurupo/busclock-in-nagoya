よくある質問

名古屋市交通局の公式アプリですか？

いいえ。Yurupo!が開発する非公式アプリです。このサイトはBusClock in Nagoyaの公式サイトで、名古屋市交通局の公式サイトではありません。

バスの現在位置や遅れはわかりますか？

現在の公開Windows版が表示するのは、時刻表上の予定発車時刻です。実際の接近状況や遅れは反映されません。乗車時は交通局の公式案内もご確認ください。

利用料金やアカウント登録は必要ですか？

無料で利用でき、アカウント登録も不要です。Windows版では設定と取得済み時刻表を端末内に保存します。

時刻表データはどこから来ていますか？

名古屋市（交通局）の「市バスGTFS-JPデータ」を検索・表示用に加工して利用しています。データ出典とライセンスはこのページ下部に記載しています。

不具合や要望はどこへ送れますか？

GitHub Issues、または公式Discordへお寄せください。アプリのバージョン・OS・操作手順を添えてもらえると確認がスムーズです。個人情報は書き込まないでください。
